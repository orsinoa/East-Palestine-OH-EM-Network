This is the GitHub for Anthony Orsino's doctoral dissertation research examining the emergency management infrastructure of the 2023 East Palestine, Ohio train derailment. 

index.html is an interactive widget of the emergency management networks I created of the disaster.
Orsino_2026_SNA_Documents_References.md and .bib are two versions of the same information. These contain the information of all publicly available documents that I used to create the networks you see in index.html. PDFs, notes, and annotations of all references are withheld to avoid copyright claims.
